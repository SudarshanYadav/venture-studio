# Moving the studio to your personal account

Package: `venture-studio-2026-11-26.zip` (built 2026-11-26 on the old machine).

1. **Unzip** anywhere on your personal machine. Check the hidden `.claude/` folder is there (it holds the team and skills).
2. **Open the folder in Claude Code** (desktop app Code tab, or run `claude` in the folder) signed in to your **personal** account. `CLAUDE.md` loads automatically, so the session is Chanakya, the CEO. Say hello and it will summarise where things stand.
3. **Optional: Git.** Install Git, then in the folder run `git init` (safe: the folder already contains a repo with one early commit) and `git add -A` then `git commit -m "Move to personal account"`. Do not add a remote or push until you decide to.
4. **Old claude.ai links do not move.** The calculator artifact https://claude.ai/artifact/CynyzBu2qb1XW1uxzsDFQ6 belongs to the old account. Open `ventures/mrudu-shower-softener/finance/calculator.html` in a browser instead, or ask Chanakya to republish it privately. To find any other old links, search the files for `claude.ai/` (found in `ORG.md`, `decisions/2026-11-25-finance-results.md`, `decisions/2026-11-25-persistent-org-setup.md`; `README.md` only links to the generic claude.ai/code page).
5. **What comes along:** the skills in `.claude/skills/` and agents in `.claude/agents/`. Founder preferences are in `founder-preferences.md`, so no per-machine memory is needed.
6. **What does not:** plugins, connectors and memory from the old account. Nothing in the studio depends on them.
7. Afterwards, ask Chanakya to have the Chief of Staff record the move as done in `ORG.md`.
